### 01. 多模态大模型怎么理解？ · 详解

**【原题速答】** 多模态架构应按编码器、连接器、训练数据、分辨率、延迟和目标任务评测，不宜作无条件排名。

**【考察意图】**

面试官想确认三件事：(1) 你能否把"多模态大模型"抽象成一条可组合的流水线（视觉编码 → 连接 → 语言解码），而不是背模型名单；(2) 你是否知道同一流水线在不同维度（数据、分辨率、延迟）上的工程设计空间会互相牵制；(3) 你是否具备"评测导向"的记忆——拒绝口头吹嘘，坚持按任务分桶比较。这是本模块的统领题，后续 5、6 题（网络结构、ViT）都是它的局部展开。

**【深度解析】**

一句话框架：**多模态大模型 = 视觉/音频编码器 E + 连接器 C + 语言模型 LM**。三个部件各自决定能力上限的一部分：

| 维度 | 设计空间 | 典型代表与取舍 |
| --- | --- | --- |
| 编码器 | CLIP ViT（判别式对比学习）、SigLIP（sigmoid 对比损失，替代 softmax 稳定批量）、自监督（MAE/DINOv2）、原生多模态联合预训练 | CLIP 特征“判别力强、细节弱”，对 OCR/细粒度计数吃亏；自监督特征位置敏感性更好，适合检测/分割 |
| 连接器 | 线性/MLP 投影、Q-Former（BLIP-2）、Perceiver Resampler（Flamingo）、交叉注意力注入、C-Abstractor、token 合并（pixel shuffle 4×） | 决定两件事：每图 token 数（延迟）与信息保真度。MLP 不丢信息但 token 多；抽象器省 token 但可能丢细粒度证据 |
| 训练数据 | 图文对（caption）、交错图文文档、指令数据、OCR/图表/界面截图、视频 | 数据配比决定能力面：只有 caption 数据的模型会在图表题上系统性失败 |
| 分辨率 | 固定单分辨率（LLaVA-1.5 的 336²）、tile 切块 AnyRes（LLaVA-1.6/4o 风格）、原生动态分辨率（Qwen2.5-VL，无重采样器，token 随分辨率线性长） | 高分辨率是 OCR/图表性能的最大单一因素：固定 336² 的模型无论多大会输给低分辨率小模型的 tile 流水线 |
| 延迟 | 视觉 token 数 × LM 规模决定 prefill 成本；量化/投机解码对图像 token 同样生效 | 1 张 1K² 图经 AnyRes 可产生数千 token，prefill 一次接近一篇长文的量级 |
| 评测 | 知识推理（MMMU）、文档（DocVQA）、图表（ChartQA）、OCR（OCRBench）、数学视觉（MathVista）、视频（Video-MME）、幻觉（POPE / HallusionBench）、GUI 定位（ScreenSpot） | **没有任何单一榜单能代表综合能力**，这正是"不宜无条件排名"的含义 |

**为什么不宜无条件排名（机制解释）**：多模态能力是六维向量的分量加权和，不同任务给出不同权重。一个只用 caption 数据训练的 70B 模型可以在 MMMU 上很高，却在 DocVQA 上输给 7B 的高分辨率 OCR 模型——因为 OCR 是分辨率瓶颈而非参数量瓶颈。评测时正确的做法是：先固定任务桶，再在桶内比较；同时报告 token 预算与延迟，避免"高分辨率换成绩"的归类错误（confounder：把分辨率增加归因于模型变强）。

**纠错注（2025-11 口径）**：本题原文答案完全正确但偏抽象，需补充一个实践更新：Q-Former / Perceiver 这类"重型抽象连接器"在 2023 曾是主线，但 2024 至今的公开领先模型（Qwen2.5-VL、InternVL3、Pixtral、Gemini 系）已普遍回归**简单连接器 + 原生动态分辨率**。面试中若把 Q-Former 当成"当前最优连接器"来推荐会被视为过时——应表述为"信息瓶颈权衡下的历史方案"。

参考资料中四篇论文的一句话核心结论：
- CLIP（arXiv:2103.00020）：4 亿自然语言图文对的对比学习，就能学到可零样本迁移的视觉表征（ImageNet 零样本 76.2%），开启"文本监督视觉"范式。
- Flamingo（arXiv:2204.14198）：冻结语言模型 + Perceiver Resampler + 门控交叉注意力 + 交错图文训练，即可在多模态少样本任务上达到当时 SOTA。
- Qwen-VL（arXiv:2308.12966）：以 256-token 重采样器 + 多任务（caption/OCR/检测框文本化）预训练，可在文本阅读与视觉定位上超越更大的通用模型。
- BLIP-2（arXiv:2301.12597）：轻量 Q-Former（可训练参数 188M）桥接冻结编码器与冻结 LLM，以约 54 倍更少的可训练参数超过 Flamingo-80B。

**【追问链纵深】**

- **追问 1：Q-Former、Perceiver Resampler、projector 三种连接器的本质差异是什么？** → 要害：全部都在回答"多少 token、保留哪些信息、是否可学习压缩"这一个问题。projector（MLP）逐 token 直译、无压缩、保真最高；Q-Former 用 32 个可学习 query 对 ViT 特征做交叉注意力抽取，把数百 token 压成 32 个，压缩即有损；Perceiver Resampler 固定输出 64 个 latent，天然适配多帧视频但仍是有损。选型 = token 预算 vs 细粒度证据需求的权衡。
  - **追问 2：为什么 2024 后大家放弃 Q-Former？** → 要害：LLaVA-1.5 实验显示同预算下"ViT + MLP + 高质量指令数据"比 Q-Former 更强；信息瓶颈在高分辨率/OCR 任务上代价放大；且 Q-Former 引入两阶段训练的复杂度与不稳定。抽象压缩的位置被外移成了"分辨率/采样策略 + LM 内长上下文"来消化。
  - **追问 3：连接器方案与训练冻结策略如何绑定？** → 要害：Q-Former/Resampler 的意义在"两端都冻结"（BLIP-2、Flamingo 时代 LLM 珍贵）；当端到端全参/LoRA 训练可行（LLaVA、Qwen-VL 全系），投影层只需自学习对齐，简单结构即可收敛。
- **追问 4：怎么给一个新多模态模型做公允评测？** → 要害：五个控制变量——分辨率（瓦片数/token 预算）、提示模板、few-shot vs zero-shot、评测集泄漏与榜单污染、幻觉口径（是否要求证据引用）。没有这些控制条件的"跑分对比"在面试中应主动降权。

### 02. 扩散模型 SNR 怎么用? · 详解

**【原题速答】** 扩散模型信噪比由信号与噪声系数之比定义，可用于时间步采样、损失加权、调度和条件路由。

**【考察意图】**

考察扩散模型是否学到"参数化"这一层：大多数人会背 DDPM 加噪公式与 ε-预测损失，但说不清**不同预测目标之间的等价换算**，更说不清 SNR 为什么能统一解释调度、加权、采样、蒸馏、路由这些看似无关的设计。这是区分"会用 stable diffusion"与"懂扩散理论"的分水岭，也是 Q04（按噪声路由专家）的理论地基。

**【深度解析】**

**第一步：写出前向过程与两个系数。** DDPM（arXiv:2006.11239）的前向加噪是逐步马尔可夫链，可合并为一步闭式：

$$x_t = a_t\,x_0 + s_t\,\varepsilon,\qquad \varepsilon\sim\mathcal N(0, I)$$

其中 $a_t=\sqrt{\bar\alpha_t}$（累计保留的信号幅度），$s_t=\sqrt{1-\bar\alpha_t}$（累计噪声幅度）。定义：

$$\mathrm{SNR}(t)\;=\;\frac{a_t^2}{s_t^2}\;=\;\frac{\bar\alpha_t}{1-\bar\alpha_t};\qquad \log\mathrm{SNR}_{\min}\to-\infty,\ \log\mathrm{SNR}_{\max}\to+\infty$$

SNR 是单调递减函数：$t=0$ 时干净图主导（SNR→∞），$t=T$ 时纯噪声（SNR→0）。

**第二步：推导三种参数化下损失与 $\|x_0-\hat x_0\|^2$ 的换算（不跳步推导）。**
记模型从任一参数化恢复 $x_0$ 的估计 $\hat x_0$，误差 $\Delta=x_0-\hat x_0$。

**(a) ε-预测（DDPM 原始目标）**：$x_0$ 可由 $x_t$ 反解：$x_0=(x_t-s_t\varepsilon)/a_t$，即 $\varepsilon=(x_t-a_t x_0)/s_t$。若模型预测 $\hat\varepsilon$、构造 $\hat x_0=(x_t-s_t\hat\varepsilon)/a_t$：

$$\varepsilon-\hat\varepsilon=\frac{a_t(x_0-\hat x_0)}{s_t}=\sqrt{\mathrm{SNR}}\cdot\Delta\ \Rightarrow\ L_\varepsilon=\|{\varepsilon-\hat\varepsilon}\|^2=\mathrm{SNR}(t)\cdot\|\Delta\|^2$$

即：**ε-预测（单位权重）= 对 $x_0$ 误差按 SNR(t) 加权**。高噪声步（低 SNR）在此目标下被降权。

**(b) x0-预测**：直接回归 $x_0$，单位权重即 $L_{x_0}=\|\Delta\|^2$：所有时间步平等。听起来最"公平"，但在 $t\to T$ 时 $x_t$ 里信号成分趋近 0，$x_0$ 几乎不可辨识，强逼模型在此回归 $x_0$ 会为大模糊目标付出全部容量——这正是早期某些 x0-参数化实践效果差的原因。

**(c) v-预测（Salimans & Ho, 渐进蒸馏式）**：定义 $v=a_t\varepsilon-s_t x_0$，满足 $\|v\|$ 量纲稳定。由 $\hat v$ 恢复 $\hat x_0$ 后：

$$v-\hat v=a_t(\varepsilon-\hat\varepsilon)-s_t(\hat x_0-x_0)=-\frac{a_t^2+s_t^2}{s_t}\Delta=-\frac{1}{s_t}\Delta\ \Rightarrow\ L_v=\frac{1}{s_t^2}\|\Delta\|^2=\big(1+\mathrm{SNR}(t)\big)\cdot\|\Delta\|^2$$

（用到 $a_t^2+s_t^2=1$。）因此三条目标与权重的互换关系全部成立：

| 参数化（单位权重） | 等价于 x0-MSE 的权重 | 等价于 ε-损失的权重 |
| --- | --- | --- |
| ε 预测 | $\ \mathrm{SNR}(t)\$ | 1 |
| x0 预测 | 1 | $\ 1/\mathrm{SNR}(t)\$ |
| v 预测 | $\ 1+\mathrm{SNR}(t)\$ | $\ 1+1/\mathrm{SNR}(t)\$ |

由第 3 行知：**v-预测按 $\mathrm{SNR}/(1+\mathrm{SNR})$ 加权后 ≡ ε-单位损失**（即渐进蒸馏文献中常引的等价式），说明 v-预测只是 SNR 加权谱系上的一个中间点：$t\to T$ 时退化为预测 $x_0$（信号已消失，只能猜内容），$t\to 0$ 时退化为预测 $\varepsilon$（噪声已消失）。

**第三步：SNR 的四大工程用途。**

1. **损失加权（Min-SNR，arXiv:2303.09556）**：单位 ε 损失虽命名平平，但对"图像重建误差"而言各 $t$ 不均衡（见 a 行）。Min-SNR 把权重定义为 $w(t)=\min\big(\mathrm{SNR}(t),\ \gamma\big)$（推荐 $\gamma=5$）：对低噪声（高 SNR）步做上限截断，避免这些步主导梯度；低 SNR 步保留按 SNR 比例的小权重，避免高噪声难步无限放大漂移，从而把各时间步的收敛速度拉平。文生图微调（含 LoRA/LCM 微调）中是标准开关。
2. **时间步采样分布**：均匀采 $t$ 意味着 SNR 域上的非均匀采样。SD3 把训练中的 $t$ 改为对 log-SNR 做 logit-normal 采样，让中高噪声段获得更多梯度——反映"低 SNR 步范数最大、最难学"的事实。
3. **调度设计**：Improved DDPM（arXiv:2102.09672）的 cosine 调度本质是把 $\sqrt{\bar\alpha_t}$ 用余弦插值铺成对 SNR 更均匀的曲线。算例：取 $\bar\alpha_t=\cos^2\!\big(\tfrac{t/T+s}{1+s}\cdot\tfrac\pi2\big)$，$s=0.008$。在 $t=T/2$ 处：$\tfrac{0.5+0.008}{1.008}\cdot\tfrac\pi2\approx0.7916$ rad，$\bar\alpha\approx\cos^2(0.7916)\approx0.494$，故 $\mathrm{SNR}\approx\tfrac{0.494}{0.506}\approx0.98\approx1$（约 0 dB）——中点处信号功率恰好等于噪声功率；线性 $\beta$ 调度在中点附近 SNR 仍高出数倍，这是 cosine 调度训练更稳的直观原因。
4. **条件/结构路由**：噪声水平是前向可算的免费条件信号，可作为专家路由依据（Q04 eDiff-I）、CFG 引导强度依据与蒸馏进度依据（渐进蒸馏先 v-预测再逐轮减半）。

**纠错注**：原文"信噪比由信号与噪声系数之比定义"正确但未给闭式；面试时务必直接写出 $\mathrm{SNR}=\bar\alpha_t/(1-\bar\alpha_t)$ 并给出 ε/x0/v 的权重换算表——这是本考点 90% 的区分度所在。

**【追问链纵深】**

- **追问 1：推断时才用得上 SNR 吗？训练/推理两侧分别在哪里发挥作用？** → 要害：训练侧——损失加权（Min-SNR）、时间步采样（logit-normal on log-SNR）；推理侧——采样调度（如把欧拉步画在 σ/logSNR 上等间距，terminal SNR 归零防止最后一步 $\Delta\varepsilon$ 突跳；这正是 Karras σ 调度要解决的问题）、CFG 的引导强度随噪声水平调度。
- **追问 2：为什么分辨率变大时通常要"时间步平移"（timestep shift）？** → 要害：分辨率↑时每像素噪音相对尺度改变，同一 $\bar\alpha_t$ 下感知噪度不同；实践上按 $t_\text{train}/t_\text{inf}$ 做整体平移（如 SD3/LCM 的 resolution shift），等价于按有效 SNR 重排采样分布。
- **追问 3：流匹配（rectified flow）与 DDPM 的 SNR 什么关系？** → 要害：SD3 论文指出 ε-预测 = 带特定噪声加权（与 SNR 谱系对应）的 velocity 预测特例；二者的训练目标可互相重参数化，推导即可在"目标之间的换算"框架内完成——这也是本题快速回答中"推导目标参数化换算、梯度尺度和 v 预测权重"问句的全部答案。
- **追问 4：梯度尺度如何被损失权重控制？** → 要害：$\partial L/\partial\theta$ 幅度被权重 $w(t)$ 缩放，把 $w(t)$ 设计为 SNR 的减函数/截断函数就是在做"时间维度上的梯度归一"，等价于重要度采样视角下 reweighting 而非 resampling——两条路径（改采样、改权重）在期望上等价，方差性质不同。

**【串联与资料】**

- [model-architecture.md](../modules/model-architecture.md) 08（DDPM 为什么随机采样时间步——正是"SNR 域采样 vs t 域采样"的另一半）、15/17（VQ-VAE——扩散之前的另一条离散生成路径，token 化与扩散的对比）。
- 参考论文一句话结论：DDPM（arXiv:2006.11239）——去噪目标可以训练出高质量生成模型，奠定 ε-预测范式；Improved DDPM（arXiv:2102.09672）——cosine 调度 + 可学习方差显著提升小图样本质量，调度本身是超参数；Min-SNR（arXiv:2303.09556）——损失按 $\min(\mathrm{SNR},\gamma)$ 截断加权可关闭不同时间步收敛速度失衡，提升文生图细节。

### 03. 均匀采样vs关键帧如何影响模型？ · 详解

**【原题速答】** 视频采帧应在视觉 token 预算内按任务选择均匀、随机、场景或事件驱动策略并保留关键时序证据。

**【考察意图】**

考察者想看：(1) 你是否意识到"视觉 token 预算"是所有视频理解的硬约束（LLM 上下文与注意力成本都是 token 的函数）；(2) 你能否对采样策略做**定量**失败分析（事件遗漏率），而不是说"关键帧更好"这种空话；(3) 是否理解采样策略与时间位置编码、时间 token 排布的耦合。这是视频 LLM 工程题，答案是策略组合而非单选。

**【深度解析】**

**核心约束：token 预算数学。** 一帧 $T\times T$（如 336²）经 patch-14 编码产生 $(336/14)^2=576$ token（以 CLIP ViT-L/14 计）。一段视频 $F$ 帧的总视觉 token $=F\times576$（有合并时除以 4，如 2×2 pixel-shuffle）。算例：10 分钟视频按 1 fps 抽取 = 600 帧 → 600×576 = 34.56 万 token。即使 2×2 合并后也达 8.64 万 token——超出多数模型的加噪预算或注意力成本控制线。所以任何模型必须先回答"多少帧、多少 token/帧"，再谈采样策略：

$$N_\text{帧}=\Big\lfloor \frac{B_\text{token}}{k\cdot576}\Big\rfloor,\quad k\in\{1,2,4\}\ (\text{空间合并率})$$

**四种策略的机制与代价。**

| 策略 | 机制 | 事件遗漏率（关键劣势） | 适用任务 |
| --- | --- | --- | --- |
| 均匀采帧 | 等间隔抽 N 帧，天然保留全局时间结构 | 事件时长 $d$、采样率 $f$：漏检概率近似 $\max(0,\,1-d\!\cdot\! f)$；例：1 fps 抽帧下 0.4 秒闪现事件漏检概率约 60% | 全局语义（总结、主题、情感） |
| 随机采样 | 等分布随机取帧 | 均匀策略同一缺陷但可做数据增强；推断不适合确定性输出 | 训练增强 |
| 场景检测（PySceneDetect，自适应阈值） | 内容感知切镜头，每镜头取代表帧 | 不漏场景切换，但长镜头内动作仍可能丢 | 剪辑、广告分析 |
| 事件/语义驱动 | 用检索/重要性打分模型挑"信息量高"帧，支持粗到细 | 概率最低但计算贵、依赖上游模型质量 | 问答、事件检索、长视频 QA |

**粗到细两段式（coarse-to-fine）为什么是长视频默认架构**：先低代价全扫（缩略图/低分辨率均匀帧）建立时间索引，再针对候选区间高分辨率细看。数学上等价于把注意力"先全局后局部"：全扫阶段把 $10^4$ 帧压成 $10^2$ 帧索引，细看阶段只在候选窗口付出大 token——把 O(全局²) 注意力降为 O(索引²+窗口²)。这与文本 RAG 的"向量召回→重排→生成"同构，只是索引对象从 chunk 变成时间段。

**时间顺序信息：排序 + 时间位置编码。** 抽帧打乱会破坏对"因果顺序"敏感的任务（事故录像里"先刹车还是先变道"）。两个补偿机制：(1) 帧序号与显式时间戳注入（Qwen2.5-VL 在每帧注入时间戳 token，帧-帧间隔由绝对秒数表示，因此非均匀抽帧也不失真——这是 Q3 问句"时间位置编码"的正解最新工程形态）；(2) 相对位置编码（3D RoPE：空间两维+时间一维 M-RoPE），使不规则采样的帧对齐到时间轴而非序列下标。

**与"均匀采样"直觉冲突的事实**：均匀采样在"帧数相同"前提下几乎总是信息上更均匀，但并不等于"更准"——视频信息熵极不均匀（多数视觉 token 是静态冗余）。VideoMAE（arXiv:2203.12602）用 tube masking 训练证明 90% 以上时间冗余可被压缩，间接支持"非均匀+事件驱动"路线。反方向也有理由：事件驱动策略对"整体氛围/节奏"任务会系统性偏采样高对比度片段，存在系统性选择偏差。

**【追问链纵深】**

- **追问 1：给一小时的监控视频做事件 QA，你会怎么设计采样？** → 要害：分层——(a) 1 fps 低分辨率全扫建索引（时间戳 token 标注）；(b) 按动作/场景变化阈值切分事件段；(c) LLM 先读索引摘要定位候选段；(d) 候选段 2–4 fps 高分辨率细看。给出 token 数学：全扫 3600 帧×16 token（严重降采样）≈5.8 万 token 可控。
  - **追问 2：帧数与每帧分辨率哪个优先？** → 要害：任务分治——时空动作（动作识别、计数）优先帧数；细粒度（文字、脸、小物体）优先分辨率；两者乘积恒定时用任务先验决定分配。这是乘积约束下的分配权衡而非两个自由变量。
- **追问 3：视频模型的时间位置编码有哪几类，各自的失败模式？** → 要害：(a) 一维序号 RoPE——非均匀采样失真；(b) 绝对时间戳注入——需要模型学会数值加减（对"前一秒发生什么"类问题更准但对平滑动作对齐较弱）；(c) 3D M-RoPE（Qwen-VL 系）——空间+时间分离，视频与同时支持，但位置外推仍受限。
  - **追问 4：流式场景（直播）怎么做？** → 要害：维护有限窗口的"当前帧 + 检出的关键帧"循环，索引由检索器异步更新；本质是把粗到细架构改成在线版，丢帧的代价由"索引在查询时即用即建"转移为实时计算成本。

### 04. MoE 专家网络怎么动态路由? · 详解

**【原题速答】** 扩散MoE可按时间步、噪声尺度或log-SNR路由专家，内容条件与软硬路由需验证负载和质量。

**【考察意图】**

这是一道把 MoE 从语言模型迁移到扩散模型的分析题。考察：(1) 你能否把"路由信号"从语言场景的 token 身份换成扩散场景的**噪声水平**（log-SNR）；(2) 你是否掌握 MoE 的两大评估学问题——负载均衡与路由塌缩——及其量化方法；(3) 你能否设计一个"等参数/等 FLOPs 消融"来证明 MoE 必要性（面试官最讨厌拿更大的 MoE 打更小的 dense）。与 model-architecture 14（MoE 提升 Agent 能力）是同一知识的两个应用域。

**【深度解析】**

**路由信号维度：扩散模型独有的"按噪声路由"。** 语言 MoE 路由依赖 token 语义；扩散模型额外有一个**前向可知、无需学习的连续条件**——当前 $x_t$ 的噪声水平。eDiff-I（arXiv:2211.01324）的核心观察：去噪过程有**功能分相**——早期步定构图/布局（对文本提示最敏感），晚期步出细节与风格（对参考图条件最敏感），单一网络继承不了这种相位分化。其解法分两层：

1. **专家去噪器集合（外层路由）**：把去噪轨迹按 SNR/噪声尺度划区间，训练多个专家网络各自负责一段，推理时按当前 $t$ 硬路由——这是显式、可解释的"时间步路由"。
2. **可条件化专家（内层路由）**：T5 文本编码与参考图特征通过注意力注入，并在去噪后期对语义相关度做门控（提升文本-图像一致性与风格迁移）。

语言侧 MoE 的路由器学习（Switch Transformer 型 top-k 硬路由）在这里改为**条件感知路由**：路由信号从 token 语义变为三元的（内容、文本条件、噪声水平）；混合软路由（soft mixture，全专家加权求和）等价于隐式 ensemble，可在训练后期替代硬路由提升平滑度。

**负载均衡与路由塌缩：量化框架。** Switch Transformer 的辅助均衡损失：

$$L_{\text{lb}}=\alpha\cdot N\cdot\sum_{i=1}^{N}\ f_i\cdot P_i$$

其中 $f_i$ = 实际分给专家 $i$ 的 token 占比，$P_i$ = 平均路由概率；两者同时均匀（$f_i=P_i=1/N$）时该项最小，防止"赢家通吃"。再加 router z-loss $L_z=\frac{1}{B}\sum_b\big(\log\textstyle\sum_i e^{z_{b,i}}\big)^2$ 抑制 logits 爆炸导致的离散路由抖动。**容量因子**（capacity factor，常规 1.0–1.25）约束单个专家的接收上限，超出容量的 token 走残差直连（不进该专家）。

**"按噪声分桶评测"（原文判别词）的正确定义**：
- 把 $t\in[0,T]$（或 log-SNR）划成 $M$ 个桶，在每桶内分别生成并计 FID / CLIP-score / 文本对齐分；
- 结论若只在全轨迹平均上 wins 而桶内某段显著回退，说明该 MoE 是"轨迹增益偷自某段"的伪收益（例如晚期细节专家弱化导致高频伪影）；
- 等价于把评测从"轨迹级"细化到"相位级"，与 Q02 的"SNR 分相"解释同构。

**算例：等参数消融。** 两个模型总参数相同：dense 20B vs MoE-16-experts top-1（每专家 2.5B FFN，其他层共享 → 激活约 6.5B/训练步）。正确实验设计须同时满足：(a) 训练 token 数相同、(b) 每步激活 FLOPs 相同、(c) 数据与调度一致；比较指标除最终 FID 外，须含**专家利用率矩阵**（横轴 t 桶、纵轴专家，格子颜色 = 份额）与路由熵（跨专家概率分布熵），否则"更多专家"只是容量优势而非路由优势。

**纠错注**：原文"内容条件与软硬路由需验证负载和质量"正确但把"内容条件"说得过泛；精确说法是路由可条件于三元组（噪声水平/文本条件/内容语义），而 **eDiff-I 的主路由信号是噪声水平**，显式可算、无需学分类器——面试时先讲时间步路由再讲内容路由，层次才对。

**【追问链纵深】**

- **追问 1：为什么扩散 MoE 还要"专家共享主干"？** → 要害：去噪是连续过程不是离散 token 流，完全独立专家会在相位边界产生不连续跳变；共享主干 + 各段独立 FFN（或分层容量复用）保证轨迹平滑性，这是语言 MoE（token 独立可断）没有的设计压力。
  - **追问 2：路由塌缩早期怎么诊断？** → 要害：训练损失曲线正常下跌但专家利用率方差暴涨（如激活率 $\max f_i/\min f_i>50$）、路由熵单调下降、z-loss 上涨三件套；第一时间降低学习率/提高均衡 α、加噪声扰动 logits（noisy top-k）。
  - **追问 3：扩散 MoE 与语言 MoE 的稠密度意义有何本质差异？** → 要害：语言的容量随数据多样性增长而无上限；扩散的容量随"噪声相位 + 内容域"两个可枚举维度增长，专家数有自然上限（eDiff-I 只需个位数专家），过量专家反而造成稀疏容量浪费。
- **追问 4：与 Q02 的 SNR 调度如何呼应？** → 要害：同一 SNR 既决定专家归属（路由）又是时间步重排/损失加权的同一坐标系——把"一个去噪轨迹不同阶段的异质性"充分表达，是这个考点的总世界观。

**【串联与资料】**

- [model-architecture.md](../modules/model-architecture.md) 14（MoE 提升 Agent 能力：语言侧 MoE 的负载均衡损失公式可直接迁移使用）；[inference-optimization.md](../modules/inference-optimization.md) 04（显存优化：专家显存换激活 FLOPs 的账本）。
- 参考论文一句话结论：DDPM（arXiv:2006.11239）——奠定 ε-预测与训练-推理一致框架，是"按相位划分去噪器"的出发点；eDiff-I（arXiv:2211.01324）——按去噪阶段训练专家去噪器集合 + 条件自注意力门控，可在不同噪声水平各展所长（构图 vs 细节/风格）。

### 05. 多模态大模型网络结构怎么搭? · 详解

**【原题速答】** LLaVA、BLIP-2与Qwen-VL都由视觉编码、连接模块和语言模型协作，但桥接与训练策略不同。

**【考察意图】**

考察架构比较能力：不是背四个模型，而是能以"每图 token 数、可训练参数、训练阶段、分辨率支持、信息瓶颈位置"五个轴横向填表，并能解释每个设计选择背后的时代约束（LLM 越贵越要冻结）。追问方向（视觉 token 压缩、cross-attention 位置、冻结策略、视觉消融）是四位一体——考的是"信息瓶颈放哪里、训练预算怎么花"。

**【深度解析】**

**主线对比表（以论文/官方口径为准）：**

| 模型 | 视觉编码 | 连接器 | 每图 token | 冻结策略 | 分辨率策略 |
| --- | --- | --- | --- | --- | --- |
| LLaVA / LLaVA-1.5 | CLIP ViT-L/14-336 | 线性 →（1.5 两层 MLP） | 576（336²/14²） | 编码器冻结（可训练反选 1.5），LM 全训；stage1 用 558K 图文对仅训投影 | 固定 336² |
| LLaVA-1.6 | CLIP ViT-L | MLP + AnyRes 瓦片 | 每瓦 576，多瓦拼接 | 同上 | 动态多瓦片 |
| BLIP-2 | 冻结 CLIP ViT-g/14 | Q-Former（32 可学习 query，188M 可训练参数） | 32 | 两端全冻结；stage1 以 ITC/ITM/ITG（图-文对比/匹配/生成）学 Q-Former，stage2 训 Q-Former→LLM 投影 | 固定（224/448 变体） |
| Flamingo | 冻结 NFNet/CLIP 系 ViT | Perceiver Resampler（64 latent）+ 门控交叉注意力层 | 64（视频逐帧） | LM 冻结，新增 xattn-dense 层；tanh 门 $\alpha_0=0$ 初始化保证训练零破坏起步 | 固定 |
| Qwen-VL | ViT-bigG/14（448²） | 单层交叉注意力 Resampler（256 query）+ 2×2 token 合并 | 256 | 三阶段全参训练：预训练（数十亿级图文+caption）→ 多任务（OCR/框回归文本化 grounding）→ SFT | 448²，bbox 文本化为 `<box>(x1,y1),(x2,y2)</box>`（0–999 归一） |

**信息瓶颈位置——cross-attention 位置：** 三个模型把瓶颈放在不同处，理解这一点就不会混淆架构：LLaVA 无压缩瓶颈（视觉 token 直接与文本 token 同进入 decoder 序列，属"早期融合"型）；BLIP-2 在编码器与 LLM 之间瓶（Q-Former）；Flamingo 在 **LM 内部逐层**注（每 $k$ 层插一个门控 xattn-dense，属于"后期融合"型，视觉 token 不占文本上下文）；Qwen-VL 在编码器后被一次性压到 256 token（早期融合但带抽象器）。

**训练数据与阶段算例（为什么"桥接与训练策略"是本质差异）**：BLIP-2 stage1 并不动 LLM 与编码器，可训练参数 188M——在 2023 初 LLM 不可全训的时代，用 54× 更少可训练参数打败 Flamingo-80B 是核心卖点；Qwen-VL 走全参路线路线，靠 grounding/OCR 多任务数据（量化到 0–999 的框文本 token）把"看图答题"扩展为"看图答题+指图定位"，这是它在中文学术、图表、UI 题目上强势的根因；LLaVA-1.5 的 insight 更简单直接——在 CLIP + MLP 上，**用高质量指令混合数据 + 高分辨率**即可大幅领先，证明此前很多连接器复杂度是无谓的。

**视觉 token 压缩谱系**（原文问句"视觉 token 消融"的标准展开）：
- 伯利无压缩（LLaVA 576 token/图）→ 2×2 合并 4×（Qwen-VL/InternVL，576→144 等价物）→ 查询抽象（Q-Former 18×、Perceiver 9×）→ attention/池化（Molmo 的池化变体）。
- 消融要领：固定下游指令数据与 LM，改变压缩率，测三类任务的 trade-off——全局语义（基本无损）、OCR/计数（2× 内基本无损、18× 明显掉）、幻觉率（压缩过度会诱导编造细节）。

**纠错注（2025-11 口径）**：原文把三者并列无误，但按 2025-11 工程实践梳理，"代表性结构"应更新为三代：一代抽象器（BLIP-2 Q-Former/Flamingo Resampler）→ 二代 MLP+瓦片（LLaVA-1.5/1.6）→ 三代**原生动态分辨率无抽象器**（Qwen2.5-VL、InternVL3、Pixtral：ViT 输出直接与 LLM 拼接，分辨率随需要长，token 数动态）。面试若只知 Q-Former/Resampler 而不知三代趋同，会被判定知识截止在 2023。研究文档佐证：2025-11 的 Gemini 3 Pro（原生多模态、1M 上下文）即三代路线的旗舰级呈现。

**【追问链纵深】**

- **追问 1：BLIP-2 为什么在 2023 是里程碑，而 2024 主流模型都不再用 Q-Former？** → 要害：它解决的时代问题是"冻结 LLM 上低成本对齐"；当可训练参数预算放宽（LoRA/全参）、端到端可行后，抽象器成为不必要的信息瓶颈（Q05 深解析第 4 段）。
  - **追问 2：冻结策略三态（全冻结/部分解冻/LM 全训）与数据规模的耦合？** → 要害：小数据（<1M 指令样本）必须冻结编码器+适度 LM；大规模（数十亿级图文）允许全参——Qwen-VL 全参三阶段 vs LLaVA "冻结+两阶段"的差别本质是数据预算差别而非"技术优劣"。
- **追问 3：视觉 token 位置编码在拼接式结构里怎么处理？** → 要害：常见三种——复用文本 RoPE 直接线性排列（简单但对图像 2D 结构丢失）；2D RoPE（Pixtral、Qwen2-VL M-RoPE 把空间两轴绑定到 RoPE）；可学习 1D 位置嵌入。拼接式架构 2D 信息损失是"图像推理需读图序"类错误（如扫表次序错位）常见根因。
  - **追问 4：LoRA 在多模态对齐域的收益边界？** → 要害：对齐层（Q-Former/投影）与 LM 适配层均可 LoRA（[fine-tuning.md](../modules/fine-tuning.md) 03）；但视觉编码器在 OCR/高分辨率场景下通常需全参或大 rank 微调——低 rank 矩阵难以补偿域迁移（文档/手写/图表与 web 图差异大）。

### 06. ViT 图像块嵌入原理与实现 · 详解

**【原题速答】** ViT将图像划分为patch，经线性投影或等价卷积得到token，再加入位置表示和可选分类token。

**【考察意图】**

看似基础题，实为三重考察：(1) 能否把"图像转序列"写成精确的张量操作与等价形式（reshape+matmul ≅ Conv2d），这是所有视觉语言模型的地基；(2) 对"为什么需要位置编码、向可变分辨率演进时位置编码怎么办"（原文追问：位置 embedding 插值、层次化）有硬核推导；(3) token 数、参数量、注意力复杂度的笔算能力。面试官常以"224² patch-16 会切出多少 token"或"换 336 后位置编码怎么办"开场检验。

**【深度解析】**

**第一步：精确操作。** 输入 $3\times224\times224$，patch 尺寸 $P=16$ → $N=(224/16)^2=196$ 个 patch。ViT-B/16 的块嵌入：

$$\mathbf z_0=\big[\mathbf x_\text{cls};\ \mathbf E\mathbf x_p^1;\dots;\mathbf E\mathbf x_p^N\big]+E_\text{pos},\qquad \mathbf E\in\mathbb R^{(P^2\cdot 3)\times D},\ D{=}768$$

**等价卷积形式**：变形 reshape+线性 ≡ 一个 $\text{Conv2d}(C{=}3,\ \text{out}{=}768,\ \text{kernel}{=}16,\ \text{stride}{=}16)$——因为步长=核时无重叠，卷积权重矩阵即 $\mathbf E$。实现上更多用等价 `einops` 重排以获得更佳 kernel 表现；若开重叠 patch（如 $P=14$、stride=14 或 conv stride 8）则 token 数变非平方数且计入边界几何，此处以不重叠为准。

**第二步：维度与基数（笔算单）**：ViT-B/16：12 层、$D=768$、12 头 → 约 86M 参数，token 序列 196+1(CLS)=197。ViT-L/14@336：24 层、$D=1024$、16 头 → 约 304M 参数，$N=(336/14)^2=576$，序列 577。注意力成本从 $197^2\approx3.9\times10^4$ 涨到 $577^2\approx3.3\times10^5$，约 **8.6 倍**——这就是"加分辨率不是免费"的量化表达，也是所有动态分辨率方案的动机。

**第三步：位置表示。** 原版 ViT 是可学习一维位置嵌入（把 2D 栅格展开为一维，不做先验假设），CLS token 为可选。

**位置嵌入插值（原文追问）**：换分辨率时序列长度变（如 14×14→24×24），解决法：
1. **一维直接截长/补零**——会破坏 2D 邻域对应关系，效果最差；
2. **先还原 2D 栅格再做双线性重采样到新栅格**——主流做法，可加 $\times\sqrt{N'/N}$ 类尺寸因子微调，是 LLaMA-VL 家族与多数开源实现选用的"粗但正确"方案；
3. **插值后继续在新分辨率上训练**——充分但最贵；实践中 interpolation-only 已能承受常见 1–3 倍比例变化，倍数过大（如 patch 从 16 改 14、或 tile 巨型化）需再训练。
4. **无需插值的方案**：连续/相对位置编码（NaViT 的 factorized 逐 patch 位置、Pixtral/Qwen2-VL 的 2D/3D RoPE——频率由坐标算出而非查表），天然适配任意栅格；NaViT（ViT 22B 后继）则把 patch 当"可变长流"打包，不再要求固定栅格。

**层次化 Transformer（原文追问）**：ViT 的 $O(N^2)$ 全局注意力在小分辨率可行、在大图不可行，层次化方案（Swin: 窗口自注意力 + 逐层 window shift；PVT: 降采样金字塔）把复杂度压到线性，代价是失去全局 receptive field 一步到底。多模态视角的注解：语言模型侧 decoder 天然"全局"，因此视觉塔内"全局性"可以部分让渡给 LM 处理——这正是"简单 ViT + 强 LM"优于"复杂视觉塔 + 弱 LM"叙事的结构性根源。

**【追问链纵深】**

- **追问 1：CLS token 为什么可有可无？** → 要害：以 [CLS] 输出做线性探针（原论文迁移学习做法）时必要；用 GAP/多 token 平均（多数 VLM 把全部 patch token 交给 LM）时不需要；保留与否只在下游 head 而非主干机制。
  - **追问 2：patch 大小与信息密度的取舍？** → 要害：patch↑ → token↓、注意力便宜但单 token 语义粗糙（细小物体跨 patch 融失）；patch↓ → 反之。patch 14（CLIP/Qwen 系）比 patch 16（原版）更细粒度是一些下游（OCRBench 定位）偶见优势的原因。
  - **追问 3：ViT 与 CNN 的结构先验差异如何影响 few-shot？** → 要害：CNN 有平移不变性与局部性归纳偏置 → 小数据占优；ViT 几乎无先验 → 大数据占优（原论文核心 statement），当数据不足时用强增强/蒸馏/掩码（DINOv2、MAE）补先验——"没有 free prior，只用数据买回来的也需更贵的训练"。
- **追问 4：视觉 token 数与 LM prefill 成本的换算？** → 要害：在 7B LM 上每千视觉 token ≈ 一篇数千字文档，AnyRes 一图可产生数千 token，视频数十帧可达数万——正常情况下 prefill 时间与 KV 显存先爆，见 [inference-optimization.md](../modules/inference-optimization.md) 01/07 与 Q03 的 token 预算公式。

**【串联与资料】**

- [model-architecture.md](../modules/model-architecture.md) 06（位置编码在语言域的演进——与视觉域同样发生"绝对→连续/RoPE"迁移）、19（SelfAttention QKV 计算——区块嵌入后每 token 都在算 QKV）、10（CNN/RNN/Transformer 选型——先验 vs 数据的老命题）；[raster 详细 FlashAttention 见 inference-optimization.md](../modules/inference-optimization.md) 03（$O(N^2)$ 激活不再显式合并成矩阵——ViT 大分辨率的前提）。
- 参考论文一句话结论：ViT（arXiv:2010.11929）——纯 Transformer 直接在 patch 序列上，在没有 CNN 归纳偏置的条件下，预训练成本更低、大数据集上精度更高，从此图像序列化成为 VLM 的标准入口。

### 07. Multi-modal RAG 原理与挑战 · 详解

**【原题速答】** 多模态RAG对文本、图像、音视频分别编码和检索，并保留空间时间锚点以支持重排、生成与引用。

**【考察意图】**

考察三个层次：(1) 概念——能否说清多模态 RAG 与文本 RAG 的本质增量（共享/异构嵌入、锚点即引用、跨模态重排）；(2) 架构——三条实现路线（统一嵌入空间 / 模态分离索引 + 跨模态融合 / VLM 视觉感知原生检索）的权重取舍；(3) 挑战——能把"保留空间时间锚点"展开成可实现的 provenance schema。这是 rag-foundations 模块对视觉域的镜像考题。

**【深度解析】**

**第一步：三种检索架构及其失败模式。**

| 路线 | 机制 | 优势 | 失败模式 |
| --- | --- | --- | --- |
| A. 统一嵌入空间 | ImageBind 式：文本/图像/音频/视频映射到同一向量空间，单索引单查询 | 一库多模态、简单 | 对齐损失：语义"相近"模态间距离并不均匀（图像嵌入聚成一团、文本另一团的 modality gap），跨模态排序质量上限低 |
| B. 模态分离 + 查询分解与融合（MuRAG 路线） | 语言与视觉各自检索器，Transformer 增强器在生成前融合 K 个多模态记忆 | 每模态用其最优检索器；融合层可变权重 | 级联误差：视觉检索错→生成错；需视觉感知的跨模态重排器 |
| C. 视觉感知原生检索（以 CrossFormer式文档检索器为代表，ColPali 后续发展） | 不经 OCR、直接对页面 patch 做 late-interaction 打分 | 表格/图表/扫描件检索最强（ViDoRe 基准分化明显） | 索引贵（patch 级交互）、需要专用重排开销 |

**第二条的锚点（provenance）schema——原文核心句"保留空间时间锚点"的可实现版**：

```json
{
  "id": "doc_0421#img_07",
  "modal": "image",
  "source": {"doc": "report_2025.pdf", "page": 7, "bbox": [384,120,890,540]},
  "media_anchor": {"video_ts": null, "audio_ts": null},
  "caption": "Q3 深圳仓周转率 x2",
  "sem_vec": [...],
  "visual_vec": [...],
  "confidence": 0.81
}
```

生成阶段对多模态 RAG 的**引用要求**：每个可被挑战的事实句必须附 $\{\text{来源}, \text{bbox/时间戳}\}$，否则在合同、保险、医疗报告场景不可用——这就是"锚点支持重排、生成与引用"的含义。

**第三步：挑战清单（每条给原因）。**
1. **共享嵌入的模态鸿沟**：对比学习把不同模态拉开为子空间，跨模态相似度分数不可直接比较（需校准温度或学习互补投影）。
2. **局部区域索引**：图像级嵌入对"图中某图例"不可寻址 → 需要 region-level 索引（以对象检测/OCR 行为粒度）或页面级 patch 索引（路线 C），token 成本与召回率成反比。
3. **跨模态重排**：文本 query 命中图像时分数不可比 → 重排器需多模态交叉编码（用 VLM 对（query, 图像）打分：如 "这幅图是否支撑以下这句事实" 的 yes/logits 分），代价高于文本 reranker 数量级。
4. **OCR/表格保真**：caption 化路线（VLM 先描述再文本检索）在表格/图表上系统性错——caption 丢失结构；VLM 视觉感知检索路线是修正而非补丁。
5. **长视频/长音频的时间锚点**：同 Q03 的时间索引；粗到细两段式。
6. **评测**：召回用 multimodal nDCG/recall@k，生成用 faithfulness + 引用正确率（citation F1），比文本 RAGAS 多出"视觉证据是否真正被引用"一维。

**纠错注**：原文 30 秒回答2含混处——"对文本、图像、音视频分别编码和检索"是路线 B 的描述，未包含路线 C（视觉感知检索）这一 2024 后的主流进化（ColPali 类页面 patch 检索无需 OCR），详解中已补；路线 A 的 ImageBind 在工程上常被高估（modality gap 使其排序质量上限受限），应用应优先路线 B/C。

**【追问链纵深】**

- **追问 1：多模态 RAG 与 Q05 的 VLM 有什么接口关系？** → 要害：RAG 的生成端就是 VLM；检索器给的可以是页面图像本身（保结构），由 VLM 做读图——"检索到高分辨率原图 + bbox 告知 VLM"是文档 QA 的当前最优实践；这把 Q07 与 Q05 的分辨率/瓦片机制直接对接。
  - **追问 2：局部区域索引怎么做才不爆炸？** → 要害：两层索引——页面级（粗召回）+ 页内行/box 级（细排），只在候选页内做区域向量计算；用（bbox + OCR 行）而非整页栅格化后全量计算。
- **追问 3：多模态重排器与文本 reranker 的核算差异？** → 要害：文本交叉编码 ~百 token×候选 vs 视觉交叉编码 ~2 千视觉 token×候选 → 9–40× 差距；工程答案是"粗召回压缩到 top-20 再视觉重排"，并尽量用小 VLM（<2B）做重排。
  - **追问 4：引用失败即拒绝的回答策略？** → 要害：标注没有锚点的声称（"我无法从文档中定位到 X"）来充当出口；在高风险场景下"拒绝优于猜测"，是 faithfulness 的一手增益。

**【串联与资料】**

- [rag-foundations.md](../modules/rag-foundations.md) 03（RAG 核心组件——多模态只改"检索 + 索引"两个组件）、05（三阶段与失败场景——"级联误差"与"生成端幻觉"都是子集）、06（RAG 解决的核心问题——多模态版"闭世界专有知识注入"）；[vector-search.md](../modules/vector-search.md) 08/09（向量检索与 FAISS——模态向量索引的底层）；[reranking.md](../modules/reranking.md) 06（多路召回与排序——跨模态重排是其视觉实例）。
- 参考论文一句话结论：MuRAG（arXiv:2210.02928）——一个统一的 Transformer 增强器为主干，把检索到的图像与文本记忆直接混入Transformer 上下文，使旧域（文本）RAG 架构放大为跨模态可推理；RA-CM3（Retrieval-Augmented Multimodal Language Modeling, arXiv:2211.12561）——在自回归多模态模型上，检索近邻图文并拼入上下文，可同时增强文本与图像两种生成的外照能力。

### 08. 弱多模态+强文本模型怎么协同? · 详解

**【原题速答】** 协同多模态系统让视觉模型产出可追溯的结构化观察，文本模型负责推理，并以低置信路由和补充视觉查询纠错。

**【考察意图】**

这是一道系统设计题而非模型题。考察：(1) 你能否设计"感知-认知分权"架构（弱 VLM 专注于看、强 LLM 专注于想），并给出可追溯 schema；(2) 你能否对置信路由做**离线定量**评估（原文追问"路由阈值如何离线评估"）；(3) 你是否理解 ROI 复查是一种"计算不对称"下的精细化纠错——多花视觉端算力换端到端准确率。面试官期待一个有决策点与预备数字的架构答案。

**【深度解析】**

**架构三件套。**

1. **结构化观察层（结构化观察 + 可追溯）**：弱 VLM 不直接访谈生成自然语言，把观察输出设计为：
```json
{"claim_id":"c1","claim":"图表 Q3 柱高于 Q2 柱","confidence":0.62,
 "evidence":{"doc":"q3.xlsx","page":1,"bbox":[405,321,640,602],"ocr_hint":"Q3: 8.4M"},
 "route":"verify"}
```
要点：声句不可是裸描述——每条必含 (a) 声称内容；(b) 置信；(c) 证据锚（bbox/时间戳/页面）；(d) 建议路由。这一层就是"视觉事实"，为 LLM 提供可验证的原子命题而非含混冗长的自由描述。
2. **推理层（强文本模型）**：L 只读结构化观察，不接触底层图像 → (a) 长上下文/复杂多步推理成本转移到更优的文本模型；(b) 文本模型不作 visual claims，绝不饶过观察层自答 "图里是什么"——否则幻觉回到系统；
3. **纠错层（低置信路由 + ROI 复查）**：对 confidence < τ 的声句触发 ROI 二次回查：crop bbox 区域放大再问（tile 化等效），计入两次代价。补一轮视觉查询可提升小字/细粒度项精度，代价为第 2 视觉编码 prefill 与 VLM 时延。

**为什么该分权有效：误差不耦合。** 单一多模态模型中视觉误差与推理误差发生在同一权重空间，诊断不可分解；分权后：感知错→由证据锚与 ROI 复查解决；推理错→由文本模型能力解决；两者错误相对独立，端到端 fail rate ≈ $p_v p_r$ 或 $p_v+p_r-p_vp_r$（取决于错误是否同向放大），为诊断收益也提供明确的接力层。这是"弱多模态+强文本"存在的核心理由 —— 不是组合妥协，而是错误解耦的架构收益。

**置信路由阈值的离线评估（原文追问）**：
- 从留出的验证集取 (观察, 真假标签)，对每个 τ 画 (精度, 覆盖率, 成本) 曲线；选 τ 使复查带来的端到端精度增益 / 复查成本比值高于纯增量阈值（ROI 复查只对 $p(\text{ROI}\text{错}|\tau)$ 大的区间划算，可先做小规模实证再全量）；
- 经验公式：$\Delta\text{Acc}(\tau)=P(\text{LLM 推理修正}<\Delta\text{观察})-c$；工程上 τ 往往取在验证集精度曲线的"陡坡"处（多数值集 τ∈[0.6,0.8] 变成常用初值，而非固定魔法数）；
- 路由不是二值：可多级（再问 → 换高分辨率 tile × 4 → 人工兜底），每级末段认证信度上限值。

**（补充视觉查询）重叠**：与跨模态重排器（Q07）同构——都是"另整一次视觉注意力"作为条件生成约束；区别在于：重排只输出打分信号，而路由复查输出完整的新观察。

**【追问链纵深】**

- **追问 1：ROI 复查怎么设计才能不循环？** → 要害：设"最多复查次数 K=2"、根据差错形态分级（OCR 数字错 → 高分辨率 tile 重读；物体属性错 → 不同 crop 重看）、复查预算（回查帧数/token 上限），并让复查请求继承证据锚（只看 bbox 附近而非重看全图——按边长 1/4 crop 即代码省 16× token）。
  - **追问 2：视觉事实如何做证据对齐？** → 要害：生成阶段强制使用"声句引用"（每 claimed 事实后括注 evidence_id）；消费端二次校验（声句内容是否与证据内 bbox 视觉语义一致，可用第二遍独立 VLM 检查）→ 形成"双 VLM 交叉审讯"——与 RLHF 的 Reward Model 交叉验证（[rlhf-alignment.md](../modules/rlhf-alignment.md) 08）同一思想。
- **追问 3：路由阈值的离线评估与在线间偏差怎么办？** → 要害：分布漂移——训练/验证分布外（新表格模板、新 OCR 类型）时 τ 失准；缓解方法：持续收集低置信样本做扩增验证集、按文档类型分桶设 τ、置信度本身做 calibration（温度标定 / verifiers 分数）。
  - **追问 4：这套架构与"新一代原生强多模态模型"是什么关系？会被淘汰吗？** → 要害：不会立刻——原因是任务侧仍需证据引用、审计日志、成本分段（弱模型走大流量）这些**系统属性**；原生强模型只是把"弱-强分权"吸收为"单模型内部分层"，结构化观察与 ROI复查的思想仍然成立。研究文档佐证：Computer Use / Operator（2024-2025，Anthropic/OpenAI 官方口径）把"视觉观察 + 结构化动作决策"确立为 Agent 原生范式，而 Skyvern 这类视觉 LLM 驱动的 pipeline 正是本题架构的工程实例——即使基座模型变强，"观察→纠错→路由"的架构骨架不变。
